                             JavaScript Documentation Page

This project is a  responsive documentation webpage built using HTML and CSS styled through basic structure  The page provides an overview of essential, including variables, data types, control flow, functions, and more.

It mimics the layout style of technical documentation sites, featuring a fixed navigation sidebar and content sections linked via internal anchors.

                      Features

Navigation Sidebar
Quick links to each documentation section using <a href="#section-id"> anchors.

Organized Content Sections
Each  topic is placed inside a <section> tag, making the structure clear and easy to navigate.

Readable Code Samples
Code blocks displayed using <pre> tags for readability.

Semantic HTML Structure
Uses <main>, <section>, <header>, and <nav> tags for better accessibility
